# 🌌 Cosmic Clash: Tic-Tac-Toe

A modern, high-performance Tic-Tac-Toe game built with a deep-space aesthetic. Featuring dynamic gradients, neon gold/purple accents, and an immersive "Cosmic" UI.

**[Live Demo](https://tic-tac-toe-eight-navy-77.vercel.app/)**

---

## ✨ Features
- **Dynamic UI:** Fluid background gradients that shift between deep black, dark blue, and purple.
- **Responsive Design:** Optimized for both desktop and mobile using `vmin` units for a "broad" look.
- **Glassmorphism:** Frosted glass effect on the game board and cells.
- **Vector Icons:** High-definition SVG icons for 'X' and 'O' embedded directly into the logic to ensure zero-loading lag.
- **Winning Animations:** Glowing neon highlights for the winning combination.

## 🛠️ Built With
- **HTML5:** Semantic structure.
- **CSS3:** Advanced flexbox/grid layouts, keyframe animations, and custom properties (CSS variables).
- **JavaScript (Vanilla):** Logic for winning conditions, state management, and dynamic DOM manipulation.
